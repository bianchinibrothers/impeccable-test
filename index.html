What it watches

Five signal families, joined to the components they belong to rather than streamed into one flat feed.

01 / SLO
SLO & error budgets
Burn-rate alerts on multi-window, multi-burn policy. Budget remaining per service, tracked against a 28-day rolling target.
02 / CHG
Deploy & change events
CI pipelines, GitOps commits, feature-flag flips, and infra applies — timestamped to the second and joined to the component that moved.
03 / VUL
Vulnerability intelligence
NVD, GHSA, and OS vendor feeds matched to running image digests, package manifests, and SBOMs. Reachability-scored, not merely present.
04 / ESC
On-call & escalation
Rotation state, ack latency, and hand-off notes. Knows whether a page belongs to an SRE, to security, or to both.
05 / IAM
Identity & access anomalies
New privilege grants, token minting, and unusual admin-API calls, placed on the same map as the reliability signal.

Who it's for

The SRE holding the pager

You inherited a system nobody has drawn in two years. When something breaks at 02:00, the first ten minutes go to working out what else is downstream of it — which is exactly the information Blastradius has already computed.

The map is built from what is actually deployed: service discovery, traces, and infrastructure state. It updates when the architecture does, not when someone remembers to update the wiki.

Primary audience

Security, on the same map

A CVE matters differently depending on where it sits. Blastradius scores advisories against the components that actually run the vulnerable build, and shows what that component would take with it.
